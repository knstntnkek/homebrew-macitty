# Knstntnkek Macitty

## How do I install these formulae?

`brew install knstntnkek/macitty/<formula>`

Or `brew tap knstntnkek/macitty` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "knstntnkek/macitty"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
